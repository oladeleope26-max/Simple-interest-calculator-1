# Simple Interest Calculator

A simple, beginner-friendly calculator to calculate Simple Interest.

## Formula
Simple Interest = (P * R * T) / 100

Where:
- **P** = Principal Amount
- **R** = Rate of Interest per year (%)
- **T** = Time Period (in years)

## Features
- Calculate Simple Interest
- Calculate Total Amount (Principal + Interest)
- Input validation
- Clean and responsive UI

## Tech Stack
- HTML
- CSS
- JavaScript

## How to Use
1. Enter Principal Amount (P)
2. Enter Rate of Interest (R)
3. Enter Time in Years (T)
4. Click Calculate
5. Result shows Interest and Total Amount

## Example
If P = 1000, R = 5%, T = 2 years
SI = (1000 * 5 * 2) / 100 = 100

Total Amount = 1100
